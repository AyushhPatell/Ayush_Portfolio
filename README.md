# Ayush Patel - Portfolio Website

A stunning, interactive portfolio website showcasing my work as a Full-Stack Developer. Built with React, TypeScript, Three.js, and Framer Motion.

## 🚀 Features

- **3D Interactive Hero Section** with floating geometric shapes and particle network
- **About Section** with animated statistics and 3D tilting card effects
- **Experience Timeline** with interactive cards and parallax effects
- **Projects Showcase** featuring MyHub and Student Observation Tool
- **Skills Constellation** with organized tech stack display
- **Unique Angle Highlight** section showcasing value propositions
- **Contact Section** with social links and resume download
- **Smooth Animations** and transitions throughout
- **Responsive Design** optimized for all devices
- **Custom Cursor Effects** for enhanced interactivity

## 🛠️ Tech Stack

- **React 19** with TypeScript
- **Vite** for fast development and building
- **Three.js** & React Three Fiber for 3D graphics
- **Framer Motion** for animations
- **Tailwind CSS** for styling
- **Lucide React** for icons

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Setup Instructions

1. **Add Your Resume**: Place your `resume.pdf` file in the `public/` directory
2. **Update Contact Information**: Update social media links and email in `src/components/ContactSection.tsx`
3. **Add Your Photo**: Replace the placeholder in `src/components/AboutSection.tsx` with your professional photo
4. **Customize Content**: Update project details, experiences, and skills as needed

## 🎨 Design Features

- **Color Schemes**: Three distinct color schemes that transition smoothly:
  - Deep Tech (navy + cyan)
  - Vibrant Energy (purple + neon cyan)
  - Elegant Contrast (dark + gold/teal)

- **3D Elements**: Interactive 3D graphics using Three.js
- **Glassmorphism**: Modern frosted glass effects on cards
- **Smooth Scrolling**: Buttery smooth scroll with section navigation
- **Responsive**: Looks great on desktop, tablet, and mobile
